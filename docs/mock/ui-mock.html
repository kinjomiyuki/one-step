OneStep UI モック(4 画面)

いまの Neumorphism(白 + 黄色)は保ったまま、「1 画面に 1 つの行動」「大きな問い」「進み具合が見える」を足した案

参考にした事例と、そこから取り入れたこと

サービス特徴(調べて分かったこと)このモックでの使い方
Brilliant1 画面に 1 つの問い。答えながら、考えを進める。レッスンごとに、問いかけで興味を引く。連続日数の目標を、少しずつ近づける1 問 1 画面、ホームの「続きの 1 問」、連続日数
Grasshopper(Google)最初は選択式で、少しずつ、自分で打つ形へ。パズルのように進むOneStep の「基礎 → クイズ → シミュレーション → 思考力」の順を、道すじとして見せる
Mimo、Sololearn5 分ほどの短いレッスン。小さな確認問題。アプリの中で、コードを実行できる「あと 3 分ほど」の表示。短く、区切って進める
Duolingo 型の画面上の細い進捗帯。下から出る、正解・不正解の帯。大きな 1 つのボタン問題と解説の画面の骨組み

  • 白い地に、黄色のアクセント。Neumorphism(盛り上がりと、へこみ)
  • アイコン、絵文字、丸い飾りは使わない(状態は、角丸の四角と文字で示す)
