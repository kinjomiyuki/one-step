# プレミアムプラン(Stripe)の設定

初級を無料にし、中級・上級とチャットの AI 回答を、月額 980 円(税込)のプレミアムプランにするための設定です。
`PREMIUM_ENABLED` を `true` にするまでは、制限も課金も始まらず、全員がこれまでどおり無料で使えます。

## しくみ

- 購入は、Stripe Checkout(Stripe の画面)で行う。カード情報は、このアプリを通らない
- データベースは使わない。サブスクの状態は、必要なときに Stripe へ問い合わせる
- 購入後、サーバーが署名付きのトークン(有効7日)を発行し、ブラウザの localStorage に保存する。アプリは、1日に1回、トークンの更新(Stripe への再確認)を依頼する
- 別の端末では、購入時のメールアドレスに届くリンク(15分有効)で、購入済みの状態に戻す
- チャットの AI 回答は、サーバー(`netlify/functions/chat.mjs`)がトークンを確かめる。費用がかかる部分は、サーバーで守る

## 設定の手順

### 1. Stripe(最初は、テストモードで行う)

1. https://dashboard.stripe.com で、アカウントを作る(テストモードのままで構わない)
2. 開発者 → API キーで、シークレットキー(`sk_test_...`)を表示して、控える
3. プロジェクトのフォルダ(`C:\dev\one-step`)で、次を実行する。商品・価格(月額 980 円)・カスタマーポータル(解約を許可)を作り、Netlify に環境変数を登録する(鍵と秘密の値は、画面に表示されない)

```
$env:STRIPE_SECRET_KEY = "sk_test_ここに鍵"
node scripts/setup-stripe.mjs --netlify --entitlement
```

何度実行しても、同じ結果になる(すでにあるものは再利用する)。`--entitlement` は、`ENTITLEMENT_SECRET` を新しく作るので、**初回だけ**付ける(やり直すと、購入者のトークンが無効になる)。本番の鍵(`sk_live_...`)は、`--live` を付けないと拒否される。

手作業でやる場合は、Stripe のダッシュボードで、商品カタログから、商品「OneStep プレミアム」(月次の継続課金、980 円)を作って価格 ID(`price_...`)を控え、設定 → Billing → カスタマーポータルで、解約を許可する。

### 2. メール送信(Resend)

別の端末で購入済みの状態に戻す、確認用のメールに使う。

1. https://resend.com でアカウントを作り、API キーを作る
2. 送信元のドメインを認証する(認証前は、自分宛てのテストしかできない)
3. 送信元の表記(例: `OneStep <noreply@あなたのドメイン>`)を決める

### 3. Netlify の環境変数

https://app.netlify.com/projects/one-step-programing/configuration/env に、すべて secret として登録する。

| 名前 | 値 |
|---|---|
| `STRIPE_SECRET_KEY` | Stripe のシークレットキー(最初は `sk_test_...`) |
| `STRIPE_PRICE_ID` | 手順 1 で控えた価格 ID(`price_...`) |
| `ENTITLEMENT_SECRET` | 32 文字以上のランダムな文字列。`node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` で作る |
| `RESEND_API_KEY` | Resend の API キー |
| `MAIL_FROM` | 送信元の表記 |
| `SITE_URL` | 任意。購入後の戻り先を固定したいとき(例: `https://one-step-programing.netlify.app`) |
| `PREMIUM_ENABLED` | **最後に** `true` にする。有料プランの開始のスイッチ |

`ENTITLEMENT_SECRET` は、画面や会話に表示せずに登録するのが安全。手元の PowerShell で、プロジェクトのフォルダ(`C:\dev\one-step`)から、次の1行を実行する(生成と登録を一度に行い、値は表示されない)。

```
npx netlify env:set ENTITLEMENT_SECRET (node -e "console.log(require('crypto').randomBytes(32).toString('hex'))") --secret
```

`ENTITLEMENT_SECRET` を変えると、発行済みのトークンがすべて無効になる(購入者は、メールで戻す必要がある)。

### 4. テストモードで確かめる(`PREMIUM_ENABLED` を `true` にしてから)

1. 初級が学べて、中級・上級は購入の画面になること
2. 「プレミアムを始める」から、Stripe の画面でテストカード `4242 4242 4242 4242`(有効期限は未来の日付、CVC は任意の3桁)を入力して購入できること
3. 戻ったあと、中級・上級が学べて、チャットで AI が答えること
4. 「契約の管理」から、解約できること
5. 別のブラウザで、「すでに購入済みの方はこちら」から、メールのリンクで戻れること

### 5. 本番へ

1. Stripe を本番モードにして、本番の商品・価格・シークレットキー(`sk_live_...`)・カスタマーポータルを、同じように設定する
2. Netlify の `STRIPE_SECRET_KEY` と `STRIPE_PRICE_ID` を、本番の値に差し替えて、再デプロイする
3. 下の「公開前に、準備が必要なもの」を済ませる

## 公開前に、準備が必要なもの(日本で有料のサービスを提供する場合)

特定商取引法に基づく表記、利用規約、プライバシーポリシーの画面は、すでに作ってある(`/tokushoho`、`/terms`、`/privacy`)。次の作業が残っている。

1. `src/data/business.js` に、販売事業者の情報(名称、運営責任者、所在地、電話番号、メールアドレス)を記入する。**すべて記入するまでは、リンクが画面に出ず、特定商取引法の表記は「準備中」と表示される**。個人で、住所や電話番号を公開しない場合の書き方は、専門家や消費者庁の案内で確認する
2. `src/data/legalTexts.js` の文面は、初期の案。返金・解約の方針(「お支払い後の返金はしない」「解約後も、支払い済みの期間は使える」)、準拠法などを、運営者が決めて、**専門家(弁護士、行政書士など)に確認してもらう**
3. 消費税の扱い(Stripe Tax を使うか、税込の価格として扱うか)を決める

記入後、購入の画面と、コース一覧の下に、3つの画面へのリンクが出る(有料プランが有効なときだけ)。Stripe の審査でも、これらのページが確認されることがある。

## 注意点と制限

- 中級・上級の学習内容は、画面のプログラム(ブラウザに配信されるファイル)に含まれている。制限は、画面側の表示で行っているため、技術のある人が、回避することは可能。確実に守りたい場合は、有料の内容を、サーバーから、トークンを確かめて配信する形にする(今後の作業)
- チャットの AI 回答は、サーバー側で確認しているため、回避できない
- 解約しても、トークンの有効期限(最大7日)までは、使える場合がある。アプリを開くたびに、1日に1回、再確認する
- Webhook は使わない。決済の失敗(支払いが止まった状態)は、次の再確認のときに反映される
- チャットは、利用ごとに Anthropic の API 料金がかかる。月の上限を、https://console.anthropic.com/settings/limits で設定しておく

## 税とインボイス(任意)

- 価格は税込(tax_behavior: inclusive)で登録済み。購入者への領収書とインボイスは、Stripe が購入と更新のたびに自動で発行する(ダッシュボードの「設定 → 請求書」で、屋号・住所・適格請求書発行事業者の登録番号を設定する)。
- Stripe Tax で税を自動計算したいときは、ダッシュボードの「Tax」で事業所の住所と日本の登録を済ませてから、Netlify の環境変数 `STRIPE_AUTOMATIC_TAX` を `true` にして再デプロイする。購入画面に、請求先住所と税番号の入力欄が出る。設定前に `true` にすると購入が失敗するので注意。
